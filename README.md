# Gioco dell'impiccato
Questa applicazione simula il gioco dell'impiccato.
Come linguaggio di programmazione è stato utilizzato il Python, mentre per la scrittura del codice è stata utilizzata l'applicazione web open-source Jupyter Notebook.

# Indice
1. main.ipynb: programma per giocare al gioco dell'impiccato
2. randomWord_function.ipynb: funzione per la generazione casuale della parola da indovinare
3. askToPlay_function.ipynb: funzione per l'avvio del gioco
4. chooseDifficulty_function.ipynb: funzione per la scelta della difficoltà di gioco
5. handleError_function.ipynb: funzione per la gestione degli errori
6. checkLetter_function.ipynb: funzione per la gestione delle varianti accentate delle vocali
7. checkSingleLetter.ipynb: funzione per la verifica della presenza della lettera nella parola da indovinare
8. checkFullWord_function.ipynb: funzione per la verifica della parola inserita con la parola da indovinare
9. checkInput_function.ipynb: funzione che combina le funzioni 5-8
10. gameOutput.ipynb: funzione per la gestione della grafica del gioco
11. askPlayAgain_function.ipynb: funzione per la gestione del riavvio del gioco

# Utilizzo
Scaricare il file ".ipynb" e aprirlo su Jupyter Notebook.
